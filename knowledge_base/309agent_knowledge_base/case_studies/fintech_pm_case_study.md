# Case Study --- Fintech Product Management (KB Fintech)

## Project Overview

Company: KB Fintech\
Role: Product Manager\
Timeline: 2019 -- 2020\
Product: Digital financial service platform

The platform aimed to simplify financial product discovery and help
users find personalized financial products such as loans and credit
products.

------------------------------------------------------------------------

# Context

Traditional financial services often overwhelm users with complex
terminology and fragmented product information.

Users struggled to:

-   understand financial options
-   compare loan products
-   make confident financial decisions

The platform's goal was to simplify financial product discovery and
improve financial decision-making.

------------------------------------------------------------------------

# Problem

Key product challenges included:

1.  **Complex financial information** Financial products contain
    complicated terms and conditions.

2.  **Low user confidence** Users were unsure which financial products
    were suitable.

3.  **Decision friction** Users needed to compare multiple products
    manually.

4.  **Poor financial data visualization** Data was presented in ways
    that were difficult to interpret.

------------------------------------------------------------------------

# Product Strategy

The product strategy focused on three principles:

1.  **Clarity** Simplify financial information so users could understand
    options quickly.

2.  **Personalization** Provide tailored product recommendations based
    on user data.

3.  **Guided decision-making** Help users move from discovery to action
    smoothly.

------------------------------------------------------------------------

# Execution

## 1. User Research

User interviews and behavioral analysis revealed:

-   users wanted simple comparisons
-   trust in financial recommendations was critical
-   transparency increased conversion rates

These insights shaped the product direction.

------------------------------------------------------------------------

## 2. Financial Data Visualization

Financial data was redesigned into clear visual components:

-   loan comparison tables
-   rate visualization charts
-   personalized financial dashboards

This improved comprehension of complex financial data.

------------------------------------------------------------------------

## 3. Recommendation Engine UX

A personalized recommendation flow was introduced.

Key features:

-   recommended loan options
-   eligibility estimates
-   interest rate comparisons

This helped users quickly identify suitable financial products.

------------------------------------------------------------------------

## 4. Product Experimentation

A/B testing was used to improve:

-   conversion flows
-   onboarding experience
-   product comparison screens

Data-driven decisions allowed the product to evolve quickly.

------------------------------------------------------------------------

# Results

Key outcomes included:

-   improved clarity of financial product information
-   increased engagement with product comparison features
-   improved user decision confidence

The platform enabled users to compare financial products more easily and
choose suitable options.

------------------------------------------------------------------------

# Lessons Learned

Important insights from this project:

1.  Financial services must prioritize trust and transparency.
2.  Data visualization dramatically improves comprehension.
3.  Product recommendations should assist decision-making rather than
    overwhelm users.
4.  Continuous experimentation improves product performance.

------------------------------------------------------------------------

# Product Impact

The product demonstrated how thoughtful UX design and product strategy
can simplify complex financial systems and improve user decision-making.
