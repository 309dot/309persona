# 309persona Case Study

## 배경
- 목표: 채용담당자가 309의 경력/사고방식을 빠르게 이해하도록 인터랙티브 Q&A 경험 제공
- 제약: 응답 속도, 답변 일관성, 근거 기반 신뢰성(환각/반복 최소화)

## 접근
1. 질문 의도 분류(협업/우선순위/채용강점/문제정의)
2. RAG 근거 검색(lexical + vector hybrid)
3. 응답 구조화 템플릿 적용 + 반복 방지 규칙
4. 실제 운영(터널/배포/로그) 기준으로 품질 루프 운영

## 결과
- 답변 구조는 가독성 있게 개선(헤드라인/리스트)
- 로컬 모델 기반 운영으로 비용 통제
- 품질 이슈(반복/메타누출)를 발견하고 개선 루프 체계화

## 교훈
- 모델 성능만으로는 품질이 오르지 않고, 검색/프롬프트/후처리 설계가 핵심
- 운영 로그를 통한 빠른 피드백 루프가 품질 안정화에 중요
