# 개발 기록 보관소

이전 개발 과정에서 쓰던 작업 기록이다. 앱은 이 폴더를 읽지 않는다. 현재 로드맵은 `docs/upgrade-plan-2026-10.md`.

| 폴더 | 원래 위치 | 내용 |
|---|---|---|
| `cursor-plans/` | `.cursor/plans/` | Cursor 기획 문서 |
| `taskmaster/` | `.taskmaster/` | Taskmaster 작업 목록(`tasks/tasks.json`) |
| `history_log/` | `history_log/` | 일자별 변경 기록 |
| `memory/` | `memory/`, `backend/scripts/update_working_memory.py` | 개발 에이전트의 작업 메모리와 이를 갱신하던 스크립트 |
